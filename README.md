## 🌟 Overview

**IntelliHire** is a cross-platform mobile application (Android & iOS) built with Flutter that automates and intelligentizes the technical hiring pipeline. It serves two distinct user roles:

- **Candidates** — Take AI-personalized technical assessments generated from their CV, answer questions via voice or MCQ, and receive an instant AI-evaluated performance report.
- **Organizations (Companies)** — Post jobs, review AI-ranked applicants, download CVs, and make hiring decisions — all from their mobile device.

The platform integrates **Groq LLM (Qwen 3-32B)** for dynamic question generation and answer evaluation, **Groq Whisper** for voice-to-text transcription, and **SignalR** for real-time notifications.

- Company & Candidate Registration with email verification
- OTP-based Forgot Password flow
- Secure token storage using `flutter_secure_storage`
- Automatic token refresh on 401 with race-condition guard

## 🏛 Architecture

IntelliHire follows **Clean Architecture** principles with a clear separation of concerns across three layers:

```
Presentation Layer  ←→  Domain Layer  ←→  Data Layer
   (Cubit/Bloc)          (UseCases)       (Repositories + DataSources)
   (Screens/Widgets)     (Entities)       (Remote APIs + Local Cache)
```

### Layer Breakdown

| Layer            | Responsibility                                                                         |
| ---------------- | -------------------------------------------------------------------------------------- |
| **Presentation** | Flutter widgets, screens, and Cubit state management                                   |
| **Domain**       | Business logic (Use Cases), abstract Repository interfaces, pure Entities              |
| **Data**         | Concrete Repository implementations, Remote Data Sources (Dio/REST), and local caching |

### Dependency Injection

All dependencies are wired via **GetIt** (`service_locator.dart`), keeping the dependency graph explicit and testable.

## 🤖 AI Integrations

### Groq Cloud API

IntelliHire integrates **Groq** as its AI backbone for two core capabilities:

#### 1. 🎯 Personalized Question Generation

- **Model:** `qwen/qwen3-32b`
- **Endpoint:** `https://api.groq.com/openai/v1/chat/completions`
- Generates exactly 10 unique, CV-tailored interview questions (mix of voice + MCQ) per session
- Uses a session seed for guaranteed question uniqueness across attempts
- Deduces technical track from CV if job title is generic

#### 2. 🎤 Voice-to-Text Transcription

- **Model:** `whisper-large-v3`
- **Endpoint:** `https://api.groq.com/openai/v1/audio/transcriptions`
- Converts candidate voice recordings (`.m4a`) to text before AI evaluation

#### 3. 📊 Answer Evaluation & Scoring

- **Model:** `qwen/qwen3-32b`
- Evaluates transcribed voice answers and MCQ selections against ideal answers
- Returns: overall AI score (0–100), accuracy %, per-question feedback with constructive commentary

### Backend REST API

- **Base URL:** `https://intellhire.runasp.net/api`
- Handles auth (JWT), candidate/company profiles, job management, applicant data, and assessment result storage

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) `^3.9.0`
- Dart SDK `^3.9.0`
- Android Studio / Xcode
- A [Groq API key](https://console.groq.com/) (free tier available)
- Git

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/intelli_hire.git
cd intelli_hire

# 2. Install Flutter dependencies
flutter pub get
```

### Environment Configuration

The app uses `flutter_dotenv` to load secrets at runtime. A `.env` file must exist at the **project root**.

1. Create a `.env` file in the project root (it is already listed in `pubspec.yaml` assets):

```dotenv
# .env
GROQ_API_KEY=your_groq_api_key_here
```

2. Obtain your key from [https://console.groq.com/keys](https://console.groq.com/keys).

#### Deep Link / OAuth Setup (Android)

For Google/Microsoft OAuth to work, the `intellihire://` custom URL scheme must be registered in `android/app/src/main/AndroidManifest.xml`. Verify the intent filter for `intellihire` scheme is present:

```xml
<intent-filter>
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data android:scheme="intellihire" android:host="external-login-callback" />
</intent-filter>
```

#### iOS Deep Link Setup

Add the `intellihire` URL scheme to `ios/Runner/Info.plist`:

```xml
<key>CFBundleURLTypes</key>
<array>
  <dict>
    <key>CFBundleURLSchemes</key>
    <array>
      <string>intellihire</string>
    </array>
  </dict>
</array>
```

### Build & Run

```bash
# Run on connected device / emulator (debug mode)
flutter run

# Run with a specific device
flutter run -d <device_id>

# List available devices
flutter devices

# Build release APK (Android)
flutter build apk --release

# Build release App Bundle (Android — recommended for Play Store)
flutter build appbundle --release

# Build release IPA (iOS — requires macOS + Xcode)
flutter build ios --release
```
